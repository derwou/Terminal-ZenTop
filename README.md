# Terminal-ZenTop
Interactive terminal shell extension for ZenTop.

## ⚠️ Important Notice

**Terminal ZenTop is an extension, not a standalone program.**
It relies heavily on variables and environment settings provided by the main `zentop` script (such as `$IDENTITY_USER`, `$REAL_HOME`, `$SCRIPT_DIR`, etc.).

You **cannot** run `Terminal ZenTop` on its own without the main `zentop` framework.
